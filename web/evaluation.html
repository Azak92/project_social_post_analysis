How to judge an output

Meaning: 2 = preserved, 1 = minor shift, 0 = changed claim, role, number, certainty or missing important detail. Fluency: 2 = natural, 1 = awkward, 0 = broken.

Style strength: 0 = ordinary wording, 1 = light characteristic phrasing, 2 = several recognizable patterns, 3 = strong cadence and vocabulary, 4 = highly characteristic delivery. Score the observed style independently of the requested level. Capitals alone do not establish style.

Also record unwanted political references, copied reference claims and instruction-following failures. Strong style never compensates for changed meaning. Automatic flags are only review cues; they are not accuracy scores.
